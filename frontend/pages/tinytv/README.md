# TinyTV

访问 `/pages/tinytv/`，观看按固定时间线循环播放的频道。依赖[网站公共认证](../../login/README.md)和[TinyTV 后端](/backend/modules/tinytv/README.md)。

## 使用

登录后显示当前节目和下一节目，季名存在时显示媒体库中的季名，否则显示季号。展开节目单可查看当前节目和之后最多 10 个节目，按频道顺序跨循环显示，不重复展开整份节目单。点击画面中央的“进入频道”开始播放，直播进度跟随后端频道时间，不从头播放，不提供暂停、拖动进度或选集操作。频道尚未开播时显示开播时间。播放成功后中央按钮消失，播放受阻或加载失败时可点击“重新进入”。

正常播放时画面右下角提供定时关闭、音量均衡、画面亮度、小窗、网页全屏和系统全屏操作，没有底部托盘、渐变遮罩或常驻播放状态文字。手机触控界面隐藏小窗和网页全屏按钮，只保留系统全屏入口。播放控制静置 2.5 秒后隐藏；电脑普通页面模式下鼠标移出播放器时立即隐藏，手机点击画面可切换显隐。移动指针或键盘操作时重新显示；等待、缓冲、报错、菜单打开和键盘聚焦操作按钮时保持显示。重要提示以左下角局部提示显示，恢复正常播放后隐藏。手机页面以贴边视频和紧凑页头呈现。

画面右下角可设置在 15、30 或 60 分钟后停止播放，也可以在当前节目结束后停止。定时生效时图标高亮，再次打开菜单可查看实时剩余时间；可以随时取消已有定时。定时结束后播放器停止、释放屏幕常亮锁，并显示重新进入频道的操作。

“音量均衡”默认关闭，开启后使用浏览器 Web Audio API 对突发响亮片段做温和的动态范围压缩；再次点击恢复原声。切换时画面短暂提示当前状态和功能，高亮图标表示正在启用。音频节点在当前页面内复用，切集或反复开关不会重新创建媒体源。浏览器、用户手势或片源不支持 Web Audio 处理时会停用该控制，频道仍使用原生声音播放。

“画面亮度”默认 100%，可在 10%～100% 范围内调低视频画面，拖动时立即生效并在当前页面切集后保持。该功能只使用 CSS 滤镜处理网页中的视频，不改变系统屏幕亮度或媒体文件。网页全屏和支持页面滤镜的标准全屏会保持当前亮度；部分移动浏览器的系统原生视频全屏和原生画中画窗口可能忽略网页滤镜。

点击画面右下角的全屏按钮进入全屏播放，并在浏览器支持时尝试锁定横屏，退出全屏时解除锁定。横屏锁定失败不影响全屏，不支持标准全屏 API 的浏览器显示提示；未提供 Apple 专用全屏适配。

小窗按钮使用浏览器原生 Picture-in-Picture API，不支持时自动隐藏。画中画窗口中的控件由浏览器提供；部分浏览器会显示进度条，但拖动后播放器会立即校准回频道当前时间。网页全屏只将播放器铺满当前网页视口，不触发系统全屏权限；按 Esc 或再次点击按钮退出。

播放使用浏览器原生 `<video>`，不附带额外解码器。片源应使用目标浏览器支持的 MP4 封装和编码；为了兼容常见桌面与移动浏览器，建议统一为 H.264 视频和 AAC 音频，并修复异常时间戳和索引信息。

播放期间通过 Screen Wake Lock API 请求屏幕常亮，缓冲期间保留；暂停、结束、报错、退出登录或离开页面时释放，切回可见页面后按播放状态重新申请。需要 HTTPS（或本机安全上下文）和浏览器支持，系统省电策略或权限限制可能拒绝常亮请求，不影响视频播放，也不会阻止手动锁屏。

## 调试点播

展开“调试点播”，输入相对于 `ALIST_ROOT` 的视频文件路径（与 `sources.json` 的 `path` 规则相同），点击“播放点播”。文件不必编排进节目单。使用当前播放器播放，画面顶部提供暂停/继续、进度拖动、前后 10 秒和“返回直播”。视频结束后停在结尾；错误时可重新提交路径或返回直播。路径错误、权限问题和浏览器不支持的格式会显示提示。

点播只存在于当前页面，刷新恢复直播，不改变节目编排、服务器时间线或其他观看者的状态。点播期间停用直播同步、边界切换和进度纠偏；返回直播会重新查询当前节目并定位实时进度。按节目结束关闭的定时在切换模式时取消，分钟定时继续有效。

## 开发与依赖

`player.js` 负责直播/点播模式、原生视频播放、频道时间校准和播放控制，`style.css` 维护本模块样式。页面通过同源 `/api/tinytv/channels/tiny/now` 认证查询节目，响应的 `playUrl` 直接为 AList `/d/...` 地址。浏览器使用该地址读取视频并跟随 AList 的下载重定向，不经过额外的直链查询接口或本站视频中转。地址不持久化；片源 CORS、Range 与地址权限要求见后端模块文档。进入频道和切集时先定位再播放；播放中的同步查询间隔和进度偏差阈值分别为 15 秒、30 秒。

## 验证

节目编排、媒体源配置、接口和直链播放说明见后端模块 README；本地启动见[网站 README](../../README.md)。修改前端脚本后可在本目录检查语法：

```bash
node --check player.js
node --test ../../../tests/test_tinytv_player.mjs
```

联调时验证当前进度播放、节目切换、小窗、网页全屏、系统全屏和登录过期处理，并在目标桌面与移动浏览器上确认片源编码兼容性。真实播放验证需要配置可访问的媒体源。

点播通过认证后的 `POST /api/tinytv/on-demand` 获取地址，具体请求和路径限制见后端模块文档。点播操作复用 `loadVideo` / `playChannel`，与频道调度分开；模式版本号会丢弃旧请求的响应和错误。

连续播放时每集后有固定 10 秒过渡余量。过渡期间优先播放完当前片尾，结束后用同一播放器加载下一集并暂停等待开播；节目单标记为“过渡中”。超出余量仍按频道时间线换源。连续切集时下一集开始不足 10 秒则优先从头播放，加载期间不追加定位耗时，随后恢复每 15 秒同步和超过 30 秒偏差的纠正；首次进入仍定位频道进度。part 之间不增加过渡。“本节目结束后关闭”在最后一个 part 自然结束时停止，未正常结束则由下一节目边界兜底。
