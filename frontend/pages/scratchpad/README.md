# Scratchpad

访问 `/pages/scratchpad/`，用于临时整理草稿和跨设备传文件，无需构建。依赖[网站公共认证](../../login/README.md)和[Scratchpad 后端](https://github.com/cloverfrog/cloverfrog.github.io-backend/blob/main/modules/scratchpad/README.md)。

## 使用

- **手动保存**：点击“保存”或按 Ctrl/Cmd+S 上传草稿；未保存修改显示 `*` 和“未保存”。输入仅存在当前页面内存中，刷新、关闭或跳转后可能丢失。
- **跨设备读取**：点击“刷新列表”获取其他设备保存的草稿。不自动同步、不检测冲突，同时编辑以最后一次保存为准。
- **草稿操作**：支持新建、切换、重命名、复制全文、完成及 8 秒撤销。Ctrl/Cmd+Enter 仅复制全文。
- **恢复缓存**：手动保存时写入 IndexedDB，网络失败后可重试或重新打开恢复；兼容旧版遗留的本机未同步草稿。保存期间继续输入的内容仍需再次保存。
- **文件速传**：独立于正文保存，支持多选逐个上传、下载、删除，单文件最大 50 MB。其他设备点击“刷新文件”查看。

上传显示进度并支持取消，不支持断点续传或自动重试。取消或超时后先刷新文件列表确认结果，避免重复上传。普通数据请求超时为 15 秒，上传、下载为 5 分钟。

## 3 天清理

草稿从最后一次保存、文件从上传开始保留 72 小时；复制和下载不续期。打开或刷新页面时清理当前账号的过期数据，上传前也会清理过期文件。无人使用页面时不执行清理，并非到点立即删除。

正在编辑或等待完成的草稿暂时保留，保存成功后重新计时。IndexedDB 恢复缓存同样保留 72 小时；旧版无时间记录的缓存从首次使用此版本起计时。清理依赖设备时钟，失败显示数量，后续操作重试。服务器备份不在清理范围内。

## 开发与依赖

| 文件 | 职责 |
| --- | --- |
| `app.mjs` | 草稿编辑、手动保存与页面交互 |
| `files.mjs` | 文件列表、上传进度、下载与删除 |
| `store.mjs` | 本机 IndexedDB 恢复缓存 |
| `retention.mjs` | 过期判断、缓存整理和云端清理 |

前端通过同源 `/api/scratchpad/*` 访问后端。接口、PocketBase 集合字段和权限规则统一维护在后端模块 README；本地启动见[网站 README](../../README.md)。

旧版 `scratchpad-auth` 独立登录缓存不再使用，重新登录后清除；既有 IndexedDB 草稿缓存保留。登录过期跳转前，请复制保留未保存内容。
